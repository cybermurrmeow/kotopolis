# Котополис

Котополис - учебный веб-сервис для небольшого приюта. В нём можно вести каталог котиков, принимать заявки на знакомство, сохранять избранное и управлять данными с учётом ролей.

Демо: [meowly.space](https://meowly.space)

![Кот с экрана входа](static/img/login-cat.gif)

## Возможности

- регистрация, вход, подтверждение почты и восстановление пароля;
- роли обычного пользователя и администратора;
- гостевой режим только для просмотра каталога и карточек;
- каталог с поиском, фильтрами и избранным;
- анкеты котиков и загрузка JPG, PNG, WebP или GIF;
- заявки на знакомство и управление их статусами;
- экспорт каталога в CSV, Excel и PDF;
- CSRF-защита, ограничение частоты запросов и безопасные cookie.

Комментарии сейчас отключены. Исторические заявки и комментарии сохраняются. Удаление аккаунта или котика с такой историей заблокировано; заявку можно закрыть сменой статуса.

## Стек

Python 3.11+, Flask, SQLAlchemy, PostgreSQL, Jinja2, Bootstrap и JavaScript. Для локальной демонстрации можно использовать SQLite.

## Структура

- `app.py` - маршруты, авторизация и основная логика;
- `models.py` - модели базы данных;
- `forms.py` - формы и серверная валидация;
- `media.py` - проверка изображений и создание превью;
- `utils.py` - экспорт и статистика;
- `templates/` и `static/` - интерфейс;
- `migrations/` - миграции базы данных;
- `manage.py` - демо-данные, администратор и пересборка превью;
- `tests/` - регрессионные тесты.

## Локальный запуск

```bash
python -m venv .venv
```

Активируйте окружение (`.venv\Scripts\Activate.ps1` в PowerShell или `source .venv/bin/activate` в Linux/macOS), затем установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и создайте секретный ключ:

```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

Запишите результат в `SECRET_KEY`, затем подготовьте базу:

```bash
flask --app app db upgrade
python manage.py seed-demo
python manage.py create-admin
python app.py
```

Сайт будет доступен по адресу `http://127.0.0.1:5000`. `PUBLIC_BASE_URL` задаёт доверенный адрес ссылок сброса пароля и не зависит от Host запроса. Для локального окружения оставьте `COOKIE_SECURE=false`; на HTTPS-сервере должно быть `true`, а `PUBLIC_BASE_URL` должен содержать реальный HTTPS-адрес.

## Изображения и GIF

При загрузке изображения создаются два превью формата 4:3: статичное для режима с уменьшенной анимацией и анимированное для обычного режима. Для уже существующих локальных файлов их можно построить командой:

```bash
python manage.py rebuild-previews
```

Исходные пользовательские загрузки не входят в репозиторий. Ограничения загрузки: 10 МБ, 12 млн пикселей на кадр, 24 млн пикселей всех исходных кадров, 20 млн пикселей всех превью. Последний бюджет допускает до 28 кадров 960x720. Длинную анимацию нужно предварительно уменьшить; её обработка в web-worker не допускается. Новые внешние ссылки должны использовать HTTPS без логина и пароля. Сервер их не скачивает.

## Проверки

```bash
pip install -r requirements-dev.txt
ruff check .
black --check .
pytest
```

Pytest всегда использует SQLite в памяти. Он игнорирует DATABASE_URL и TEST_DATABASE_URL и дополнительно проверяет реальный engine перед созданием и очисткой таблиц. Проверки PostgreSQL вынесены в отдельный инструмент с собственным адресом и случайными схемами:

```bash
python checks/postgres_review.py
python checks/postgres_adoption_concurrency.py
```

Нужна переменная `REVIEW_POSTGRES_URL`, указывающая на отдельную локальную БД с суффиксом `_review`; драйвер задаётся как `postgresql+psycopg2`. Для проверки конкурентных заявок обязательно задайте порт, отличный от 5432. Инструменты отказываются подключаться к удалённым адресам и не используют `.env`. Они создают и удаляют только свои случайные схемы; существующие таблицы не затрагивают. Для одноразового PostgreSQL 17 можно использовать `compose.review.yml`, предварительно задав `REVIEW_POSTGRES_PASSWORD`. Данные контейнера хранятся в tmpfs.

Воспроизводимый браузерный smoke-test:

```bash
python -m pip install -r requirements-browser.txt
python -m playwright install chromium webkit
python checks/browser_smoke.py --output ../browser-results
python checks/theme_smoke.py --output ../theme-results
python checks/mobile_layout.py --output ../mobile-results
python checks/mobile_layout.py --extended --output ../extended-results
```

Проверка использует временную SQLite, синтетические аккаунты, миграции и локальный HTTP-сервер. Проверяет CSRF в реальном браузере, гостевой вход, пользовательские/административные страницы, предупреждение при смене email и AJAX избранного. Скриншоты и JSON сохраняются вне исходников. Проверка PostgreSQL не заменяет функциональный или нагрузочный прогон на PostgreSQL.

Устройство проекта и результаты проверок: [docs/REVIEW_GUIDE.md](docs/REVIEW_GUIDE.md). Список маршрутов: [docs/PROJECT_MAP.md](docs/PROJECT_MAP.md).

Для PDF на Linux нужен установленный шрифт с кириллицей, например DejaVu Sans из пакета fonts-dejavu-core. Windows-проверка использовала системный Arial. Отсутствие подходящего шрифта вызывает явную ошибку; воспроизводимый контейнер приложения пока не подготовлен.

## Production

Для существующей базы сначала сделайте резервную копию. Если схема была создана до появления миграций, отметьте базовую ревизию и только после проверки примените следующую:

```bash
flask --app app db stamp 713e4cad75bd
flask --app app db upgrade
```

Перед stamp нужно сравнить существующую схему с базовой ревизией; stamp сам этого не проверяет. Следующая миграция добавляет отсутствующий признак временного пароля или принимает уже существующий BOOLEAN, сохраняя TRUE и исправляя NULL. Она переводит старые роли в `user`. Ревизия c12ea302f004 добавляет уникальные индексы активных и одобренных заявок; при исторических конфликтах останавливается, ничего не удаляя. Автоматический downgrade ревизии паролей запрещён; откат требует проверенной резервной копии. Миграции с инспекцией схемы выполняются только online.

Для нескольких процессов Flask-Limiter нужно общее хранилище через `RATELIMIT_STORAGE_URI`; для Redis установите `Flask-Limiter[redis]==4.1.1`. Локальная память не обеспечивает общий лимит между workers. Обновление production в рамках этого ревью не выполнялось.

Ревизия d02f042bae17 добавляет unique index lower(username). Если старые логины различаются только регистром по правилам БД, миграция останавливается до изменения данных. SQLite и PostgreSQL используют разные правила Unicode/collation; одинаковое поведение всех русскоязычных имён отдельно не подтверждено.

## Данные и публикация

В репозиторий не входят `.env`, базы, дампы, пользовательские загрузки, логи и резервные копии. Перед первым публичным push нужно проверить не только текущие файлы, но и всю историю Git. Удаление секрета новым коммитом не удаляет его из предыдущих коммитов.

Права на публикацию `static/img/login-cat.gif`, иконок и других визуальных материалов нужно подтвердить отдельно. Если источник или лицензия неизвестны, безопаснее заменить файл собственным.
